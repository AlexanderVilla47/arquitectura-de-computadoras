# Buzón de entrada

Tirá acá cualquier material nuevo que encuentres, **sin pensar dónde va**.

La próxima vez que corras `npm run sync`, los archivos de esta carpeta aparecen
listados como *pendientes de clasificar*. De ahí se mueven a la sección que
corresponda y se vuelve a correr `npm run actualizar`.

Esta carpeta **no se publica** en el sitio: es sólo una bandeja de paso.
